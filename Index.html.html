1. Inventory File (hosts)

Define the servers Ansible should manage. Save this as hosts.

[webservers]
web1 ansible_host=172.31.32.165
web2 ansible_host=172.31.43.70

[webservers:vars]
ansible_user=ec2-user
# Optional: specify your SSH key
# ansible_ssh_private_key_file=~/.ssh/my-key.pem

Test the inventory:

ansible-inventory -i hosts --list

2. Sample Playbook (setup.yml)

This example installs and starts Nginx on Amazon Linux/RHEL-like hosts.

---
- name: Install and start nginx
  hosts: webservers
  become: true
  tasks:
    - name: Install nginx
      ansible.builtin.dnf:
        name: nginx
        state: present

    - name: Start and enable nginx
      ansible.builtin.service:
        name: nginx
        state: started
        enabled: true

Save as setup.yml. For Ubuntu/Debian, use ansible.builtin.apt instead of dnf.

💡 Quick Learning Notes

  1. Ansible uses SSH to connect to managed Linux hosts; no agent is usually required.
  2. An inventory defines which hosts or groups Ansible manages.
  3. A playbook is a YAML file describing plays and tasks.
  4. Modules such as dnf, service, copy, and user perform tasks.
  5. Use become: true when a task needs privilege escalation, and configure sudo appropriately.
Tip: Start with ansible all -i hosts -m ping, then try a small playbook on a test server before using production hosts.

Quick Guide: First-Time Setup

1. Check Ansible installation

Run ansible --version on your control node. Install Ansible using the method recommended for your operating system.

2. Configure SSH access

Confirm the control node can SSH to each managed host using the correct username and private key. Restrict private-key permissions, for example with chmod 400 my-key.pem.

3. Test before changing servers

Run ansible -i hosts webservers -m ping. Ansible's ping module checks connectivity and Python availability; it is not an ICMP network ping.

4. Execute the playbook

Run ansible-playbook -i hosts setup.yml --syntax-check first, then ansible-playbook -i hosts setup.yml. Review the output for failed or unreachable hosts.
